Setup Guide

  1. Go to Azure Portal → Azure Active Directory → App registrations
  2. Click "New registration" — name it "M&M Sales Intelligence"
  3. Set redirect URI to your Sales Intelligence URL
  4. Under API permissions, add: Calendars.ReadWrite, OnlineMeetings.ReadWrite
  5. Create a Client Secret under "Certificates & secrets"
  6. Copy the Tenant ID, Client ID, and Client Secret above
